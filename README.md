# grunt_reborn

小兵重来 · Grunt Reborn — 俯视角像素自动战斗肉鸽卡牌游戏。

玩家不直接操控移动/攻击：主角小兵全程自动行动；每 10 秒开启出牌窗口，玩家打出卡牌改变主角行为、加 buff、释放瞬发效果、召唤护卫、给主角新增被动技能。主角阵亡本局结束，消耗轮回进度重生，随机切换武将重新开局。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run test       # 单元测试
npm run test:e2e   # 无头文本 E2E
```
